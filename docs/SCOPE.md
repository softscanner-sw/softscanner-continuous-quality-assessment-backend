# Scope: dissertation model, implementation inventory and validation status

## Two different enumerations

The dissertation (Chapter 4) presents a **bounded conceptual quality model**:
- **34 quality goals**: six top-level characteristics and 28 subordinate goals;
- **eight operationalized leaf goals** within its stated scope.

The code at the tagged revision `thesis-nfa-impl-2026-11-16` contains a **wider implementation inventory**:

| Item                                           | Count                                                                                                                                             | Where it is checked                                                                                |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Goal nodes                                     | 49 (10 composite, 39 leaves; 9 top-level characteristics)                                                                                         | `test/ssqmm-mapping.regression.test.js` ("goal registration: 49 goals, 10 composite, 9 top-level") |
| Leaf goals with goal-to-metric mappings        | 9: Popularity, Activity, Loyalty, Time Behavior, Resource Utilization, Confidentiality, Non-repudiation, Ecological Footprint, Physical Footprint | `src/core/metrics/metrics-mappers.ts`; `test/ssqmm-mapping.regression.test.js`                     |
| Metrics with declared observation requirements | 49                                                                                                                                                | `src/core/metrics/metric-observables.ts`; `test/observable-registry.regression.test.js`            |

The two enumerations describe different scopes. The code includes goal nodes and mappings that the dissertation's conceptual model does not count or does not treat as established. For example, *Physical Footprint* reuses Resource Utilization metrics. Neither enumeration was adjusted to match the other.

| Integrity                                                                                        | goal node only; no metrics                                                                                                                                                                                     |
| Goal-scoped instrumentation overhead                                                             | measured in EQ2 for agents generated by this revision                                                                                            |
| Score calibration, weight sensitivity, stability across releases                                 | not evaluated                                                                                                                                                                                                  |

The regression tests check structural properties and specific defects fixed during consolidation:
- mapping and registry consistency;
- module selection;
- injection and cleanup;
- finite metric values, normalization polarity and cycle records.

They do not establish that a metric measures the quality attribute it names.
